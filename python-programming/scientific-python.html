Start here · the spine

Every scientific-computing question is a question about shape, missingness, and what the numbers were fitted on.

Which axis does this operation walk along, and which one disappears? Which values are really absent, including the ?, unknown, 999 and impossible zeros that isna() cannot see? Were these statistics, scalers and scores computed on the rows you are about to judge them by? Most of the errors in this course's slides, notebooks and marked answers are one of those three questions answered wrongly. The ten stages below are the order a notebook should run in. Click one to see what happens there and which classic error lives in it.

ShapeAxes, broadcasting, reshape order, axis=0 vs axis=1, one row per what.
MissingnessNaN versus sentinel codes, what dropna removes, how many rows a plot or model really used.
Fitted onTraining versus held-out rows, preprocessing learned before the split, scores reported against a baseline.

Built from the 56 files in 01_Scientific_Computing (49 after setting aside exact duplicates and notebook checkpoints): the NumPy, SciPy, data-analytics and scikit-learn decks, the lecture PDFs, Bressert's SciPy and NumPy (O'Reilly, 2012), the IBM NumPy, pandas, wrangling and EDA labs, the weekly homework and case studies with their saved answers, the midterm, the eight CSV and three Excel datasets, two .py files, and the folder's own review, SUMMARY.md. Every card cites its sources. Text marked not in the course material was added to keep a topic coherent.

Scope: Python only. NUMPY.pptx slides 16–25 and DATA_ANALYTICS pages 26–34 are written in MATLAB syntax under NumPy and Matplotlib titles; they appear here only as corrections giving the Python form. Midterm Section 3 (input, loops and a class) is core Python and belongs to the Python Fundamentals sheet. The empty scipy.spatial placeholder is covered from the book's spatial section; the SciPy outline's "temporal analysis" has no content anywhere in the folder.

Versions: code was written for and, where the library was available, run with Python 3.12, NumPy 2.4, pandas 3.0, SciPy 1.18, Matplotlib 3.11 and seaborn 0.13. scikit-learn 1.9 snippets were checked against its source but could not be executed on the build machine. Several course files predate these versions; the corrections flag removed APIs. Scores and ticks are stored only in this browser.
