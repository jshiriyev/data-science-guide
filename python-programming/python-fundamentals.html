Start here · the spine

Every Python question is a question about names, types and mutability.

Which object does this name point to? What does that object's type allow? Can it change in place, and who else can see the change? Almost every bug in the course notebooks, from stale outputs to shadowed built-ins and silently shared lists, is one of those three questions answered wrongly. The ten stages below are what Python does with your code, in order. Click one to see what happens there and which classic error lives in it.
