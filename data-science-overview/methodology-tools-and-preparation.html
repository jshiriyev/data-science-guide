Start here · the spine

Every data-science result is only as good as the question it answers, the definitions it was built on, and the rows it was checked against.

The methodology deck says it as ten stages; the tools deck names what runs each stage; the SPSS lesson, notebooks and streams show the stages being carried out. Almost every error in this folder is one of three failures: a question that was never pinned down, a definition left implicit (what a duplicate is, what “missing” means, whether 39 is in the thirties), or a result checked against the rows that produced it. The cycle below is the order the course teaches. Click a stage to see what happens there and which error the folder makes in it.
